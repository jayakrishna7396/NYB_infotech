1. Introduction to HTML

HTML stands for HyperText Markup Language. It is used to create the structure of web pages.

2. HTML Document Structure

An HTML document mainly contains: DOCTYPE, html, head, and body.

3. DOCTYPE

DOCTYPE tells the browser that we are using HTML5.

Example: <!DOCTYPE html>

4. HTML, Head and Body

HTML is the main container. Head contains webpage information. Body contains visible webpage content.

5. Headings

Headings are used for titles and headings. HTML provides h1 to h6.

Heading 1

Heading 2

Heading 3

6. Paragraphs

The p tag is used to display a paragraph.

7. Line Breaks

Hello
My name is Krishna
I am learning HTML

br is used to move text to the next line.

8. Horizontal Rules

Before the horizontal line

After the horizontal line

hr is used to create a horizontal line.

9. Text Formatting Tags

9.1 Bold

This is bold text.

b is used to make text bold.

9.2 Italic

This is italic text.

i is used to display text in italic style.

9.3 Underline

This is underlined text.

u is used to underline text.

9.4 Strong

This is important text.

strong shows that the text is important.

9.5 Emphasis

This text is emphasized.

em is used to give emphasis to text.

9.6 Highlight

This text is highlighted.

mark is used to highlight text.

9.7 Subscript

Water: H2O

sub displays text below the normal line.

9.8 Superscript

Square: X2

sup displays text above the normal line.

10. HTML Comments

Comments are used to write notes inside HTML code.

Comments are not displayed on the webpage.

11. HTML Entities

Entities are used to display special characters.

Less than: <

Greater than: >

Ampersand: &

Copyright: ©

13. Block-level Elements

Block-level elements normally start on a new line.

Block Element 1
Block Element 2

Examples: div, p, h1, section

14. Inline Elements

Inline elements normally stay on the same line.

First Second Third

Examples: span, b, i, strong

15. Semantic HTML
